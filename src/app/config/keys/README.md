# Unused leftover key files

The files in this directory (`*.key`) are **not** used at runtime.

RS256 material is generated by `npm run keys:generate` into `keys/jwt-*.pem` at
the **repository root**. Config reads `JWT_*_KEY_PATH`.

Do not point production mounts here. Do not commit PEMs. See
[keys/README.md](../../../keys/README.md).
